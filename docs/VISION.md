# LiRythme

## Linear Parallel Hybrid Rhythm Companion

**LiRythme extends the creative capabilities of your drum machine.**

It is not a drum machine.

It is not a DAW.

It is a rhythmic composition instrument designed to work alongside the instruments you already love.

Hybrid means freedom.

The same rhythmic engine can drive MIDI instruments,
audio trigger/gate interfaces,
and future hardware without changing the workflow.

---

## Philosophy

Workflow before features.

Performance before programming.

Complement, don't replace.

Minimal interface. Maximum creativity.

Every line of code must make LiRythme more enjoyable to play.
