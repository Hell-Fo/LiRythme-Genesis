# Dedicated USB CV/Gate Interface

Status
ARK

Generation
New Testament (V2)

Description

Dedicated USB hardware interface providing independent CV/Gate outputs
without requiring a professional multichannel audio interface.

Reason for postponement

Genesis focuses on the simplest possible hardware:
Stereo Audio → Audio-to-Gate module.

Benefits

- Independent CV outputs
- Independent Gate outputs
- Lower latency
- Better voltage accuracy
- Simpler setup
- Native note sequencing
